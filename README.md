## 📖 Project Overview

The `pydantic_validation.py` script covers:

* ✅ Creating models with **Pydantic’s `BaseModel`**
* ✅ Enforcing strict data types and auto-validation
* ✅ Handling exceptions when invalid data is passed
* ✅ Using **optional fields** via `typing.Optional`
* ✅ Clean printing of model instances

This project demonstrates the **importance of type safety** and how Pydantic can **reduce runtime errors** effectively.

## 🛠️ Features Covered

✅ Basic Pydantic model creation (`Person`, `Employee`)

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/pydantic-validation.git
   cd pydantic-validation
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the script:

   ```bash
   python pydantic_validation.py
   ```

✅ You’ll see validated models and error messages when invalid data is passed.
